# Micro-gestes

Application compagnon du livre *Comprendre ne suffit pas* de Yann Riguidel :
un parcours de 28 jours de micro-gestes, et un volet pour gérer le trac.

- Application web installable (PWA), qui fonctionne hors connexion.
- Les données des utilisateurs restent sur leur téléphone. Voir [DONNEES.md](DONNEES.md).
- Contenu : Yann Riguidel. Développement et maintenance : Isabelle Courtiau.

## Publier une nouvelle version

1. Changer le numéro dans `index.html` (`APP_VERSION`) et dans `sw.js` (`V`).
2. Lancer les tests décrits dans [DONNEES.md](DONNEES.md).
3. Enregistrer les fichiers dans ce dépôt.
